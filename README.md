# Luxury Supper Club Website

## Overview
A high-end, intimate supper club website where stories are cooked, not told. This website preserves all the sophisticated architecture and animations of the original design while transforming it into a warm, inviting culinary experience.

## Design Philosophy

### Visual Direction
- **Light & Warm**: Soft ivory base with warm, food-friendly tones
- **Elegant & Inviting**: Boutique dining aesthetics inspired by Michelin-star restaurants
- **Cultural Heritage**: Subtle Indian culinary richness presented with refinement
- **Organic Animations**: Smooth, gentle transitions that feel natural

### Color Palette
- **Primary**: `#faf8f5` (Soft Ivory)
- **Secondary**: `#f5f1eb` (Warm Beige)
- **Tertiary**: `#ebe6dd` (Linen)
- **Accent Copper**: `#a67c52` (Burnt Copper)
- **Accent Olive**: `#7a8450` (Sage Green)
- **Accent Brass**: `#b8956a` (Muted Gold)

## Technical Stack

### Files
- `index.html` - Semantic HTML structure
- `styles.css` - Complete design system with CSS custom properties
- `script.js` - Interactive features and animations

### Typography
- **Display**: Playfair Display (Serif) - Editorial elegance
- **Body**: Inter (Sans-serif) - Clean readability

### Animations
All animations have been softened to feel organic:
- Slower particle movements (15-45s duration)
- Gentler hover effects (3-5px transforms instead of 10px)
- Smooth ease-in-out transitions (0.5-1s)
- Reduced opacity variations for subtlety

### Responsive Design
- Mobile-first approach
- Fully responsive across all devices
- Touch-friendly interactions
- Optimized for food photography clarity

## Key Changes from Original

### Color Transformation
- Dark background → Light, warm ivory
- Bright accent colors → Muted, food-friendly tones
- High contrast → Soft, inviting contrast

### Content Transformation
- "Cinematic Universe" → "Supper Club"
- "Stories/Legends" → "Cooked, Not Told"
- "Creations" → "The Menu"
- "Themes" → "Experience"
- Portfolio items → Menu dishes
- Abstract concepts → Chef's principles

### Animation Philosophy
- Sharp/aggressive → Smooth/organic
- Fast (0.3-0.6s) → Gentle (0.5-1s)
- Bold movements → Subtle transitions
- Technology feel → Natural, breathing feel

## Usage

### Opening the Website
Simply open `index.html` in any modern browser.

### Customization
1. Replace SVG placeholders with actual food photography
2. Update chef's story in Philosophy section
3. Add real menu items with descriptions
4. Connect form to backend for reservations
5. Update social media links in footer

### Adding New Menu Items
Menu items use a card-based system. Copy the `.creation-card` structure and update:
- Image/SVG placeholder
- Category label
- Dish title
- Description

### Modifying Colors
All colors are defined as CSS custom properties in `:root` at the top of `styles.css`.

## Philosophy Behind the Design

This website whispers luxury—it doesn't shout. Every detail reflects the chef's philosophy:

- **Patience**: Slow, organic animations like sauce reducing
- **Quality**: Clean code, no shortcuts
- **Care**: Attention to every micro-interaction
- **Heritage**: Warm tones that honor tradition
- **Intention**: Every element has purpose

The design invites rather than advertises. It feels like a private invitation to an intimate dining experience.
